โปรเจกต์พัฒนาเกมต่อสู้ 2D ด้วย Unity (C#) โดยรับผิดชอบการเขียนโปรแกรมและเชื่อมต่อบอร์ด Micro:bit เพื่อใช้เป็นคอนโทรลเลอร์บังคับเกม 
มีเป้าหมายเพื่อศึกษาและต่อยอดความเข้าใจในการเชื่อมต่อฮาร์ดแวร์เข้ากับการพัฒนาซอฟต์แวร์ พร้อมทั้งนำผลงานไปจัดแสดงและเปิดให้ผู้เข้าร่วมทดลองเล่นในงานวันวิชาการของโรงเรียน
